# Lab 2 – Tidying, Cleaning, Imputation, and Outlier Detection

The objective of this lab is to practice different data preprocessing techniques used before applying machine learning models. The project works with four datasets and includes data tidying, data cleaning, missing-value handling, imputation, visualization, and outlier detection.

## Setup

Create a virtual environment:

```bash
python -m venv .venv
```

Activate the environment on Windows:

```bash
.venv\Scripts\activate
```

Install the required packages:

```bash
pip install -r requirements.txt
```

## Running the Project

Start Jupyter Notebook:

```bash
jupyter notebook
```

Then open:

```text
Notebooks/week5Lab.ipynb
```

The notebook should be executed from beginning to end using **Restart Kernel and Run All**

## Reproducibility

The project uses relative paths and a `requirements.txt` file so the notebook can be executed in another Python environment.

The final notebook should be tested from top to bottom using a clean environment before submission.
